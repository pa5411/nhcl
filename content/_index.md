## Our History

<div id="dynamic-timeline-container">

{{< timeline >}}

{{< timelineItem icon="star" header="Library Closure" badge="up to 2015" >}}
Until 2015, North Harrow Community Library was part of the Harrow Library Services, run by Harrow Council. Many of our visitors and volunteers have fond memories of the Library during this time. But in June 2015, North Harrow Library was closed following government cuts. These cuts saw the loss of four libraries in Harrow alone.

{{< /timelineItem >}}

{{< timelineItem icon="star" header="A Crazy Plan" badge="2015-2018" >}}
The North Harrow Library Trust was formed to keep North Harrow Library open. But when it was clear that the Library would close, the Trust decided to work on an even crazier plan. They dreamed of turning the unused building into a working community library and space, run purely by volunteers. It took countless petitions, surveys, business plans and contracts for the dream to become reality. Three years later, we finally received the keys to North Harrow Community Library.

The hard work had only just begun. Having been shut since 2015, there were three years’ worth of dust to clear. Then a million other tasks: organising the books; setting up a brand-new computer record system for the library catalogue; liaising with the local community and businesses; everything was done and is done by unpaid volunteers giving up their time for free.
{{< /timelineItem >}}

<div class="timeline-scroll-trigger" data-background="images/home-gallery/library-fun-day-6.jpg">
{{< timelineItem icon="star" header="Grand Reopening" badge="September 2018" >}}

We opened our doors to the public in September 2018 – a new chapter in the life of the Library. Visitors to our Library were welcomed over the threshold to enjoy the community space our volunteers had rebuilt. They could join Rhyme Time, led by our fantastic volunteer storyteller. They could take out books, use our computers, attend events with authors and join classes that were held at the Library. At every visit, they would meet our friendly volunteers who give up their time to ensure everyone has access to library services.

{{< timelineItem icon="star" header="Moving Online" badge="March 2020" >}}
In March 2020, North Harrow Library was again forced to close, this time due to lockdown. But we were not going to leave our members on their own. So during this time, our tireless volunteers worked hard to maintain that sense of community that is so essential to life here in Harrow. Events that would usually take place in the Library, such as Rhyme Time and author visits, were moved online. Our YouTube channel kept people informed and entertained. We stayed in touch through Instagram, Facebook and Twitter.

{{< timelineItem icon="heart" header="Covid" badge="2021" >}}
It was wth great sadness that we announced the passing of one of our volunteers, Neeta Thakkar. Neeta was lovely and endlessly giving. She, along with some of our other volunteers, organised our annual Diwali celebrations, donated food to many of our fundraising events and was in Tuesday afternoons to help patrons. She had a big heart, buckets of empathy and she was kind. She is sorely missed at the library and by everyone who knew her.

<script>
function initDynamicTimeline()
{
    const container = document.getElementById("dynamic-timeline-container");
    if (!container)
    {
        return;
    }

    let bgElement = document.getElementById("dynamic-scroll-bg");
    if (!bgElement)
    {
        bgElement = document.createElement("div");
        bgElement.id = "dynamic-scroll-bg";
        document.body.appendChild(bgElement);
    }

    const items = document.querySelectorAll(".timeline-scroll-trigger");
    const activeElements = new Set();
    let clearImageTimeout = null;

    const observerOptions =
    {
        root: null,
        rootMargin: "-30% 0px -30% 0px",
        threshold: 0.1
    };

    const observer = new IntersectionObserver(function (entries)
    {
        entries.forEach(entry =>
        {
            if (entry.isIntersecting)
            {
                activeElements.add(entry.target);

                if (clearImageTimeout)
                {
                    clearTimeout(clearImageTimeout);
                }

                const newBg = entry.target.getAttribute("data-background");
                if (newBg)
                {
                    bgElement.style.backgroundImage = "url('" + newBg + "')";
                    bgElement.classList.add("is-active");
                }
            }
            else
            {
                activeElements.delete(entry.target);

                if (activeElements.size === 0)
                {
                    bgElement.classList.remove("is-active");

                    clearImageTimeout = setTimeout(function ()
                    {
                        if (activeElements.size === 0)
                        {
                            bgElement.style.backgroundImage = "none";
                        }
                    }, 800);
                }
                else
                {
                    const remainingElement = Array.from(activeElements).pop();
                    const fallbackBg = remainingElement.getAttribute("data-background");
                    bgElement.style.backgroundImage = "url('" + fallbackBg + "')";
                }
            }
        });
    }, observerOptions);

    items.forEach(item => observer.observe(item));
}

document.addEventListener("DOMContentLoaded", initDynamicTimeline);
</script>
